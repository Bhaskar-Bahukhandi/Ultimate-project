## ⚙️ Import Settings for Godot

### For Pixel Art Sprites
1. Select the imported image
2. In Import tab:
   - **Filter**: Nearest
   - **Mipmaps**: Disabled
   - **Compress**: Lossless
3. Click "Reimport"

### For Tilesets
1. Import as above
2. Create TileSet resource
3. Set tile size (usually 16x16 or 32x32)

### For Audio
1. **Music**: Import as .ogg (looped)
2. **SFX**: Import as .wav (short)
3. Enable "Loop" for music tracks

## 🚀 Quick Start Workflow

### Step 1: Download Priority Assets
Start with these for the prototype:
1. ✅ Sprout Lands (Oakhaven tiles)
2. ✅ Mystic Woods (Oakhaven forest)
3. ✅ Slime sprites (Tutorial enemy)
4. ✅ GothicVania (looks amazing, FREE)
5. ✅ Underwater pack by Ansimuz (FREE, high quality)

### Step 2: Create Folder Structure
Run this in the Godot project root:
```bash
mkdir -p assets/sprites/enemies/oakhaven
mkdir -p assets/sprites/enemies/ironhold
mkdir -p assets/tilesets/oakhaven
mkdir -p assets/backgrounds
```

### Step 3: Import to Godot
1. Copy downloaded files to appropriate folders
2. Godot will auto-detect them
3. Set import settings as described above

### Step 4: Activate Asset Manager
The prototype includes an `AssetManager` script that automatically:
- Detects when real assets are present
- Switches from placeholders to real sprites
- Updates scenes dynamically

## 🔄 Asset Manager Auto-Detection

The prototype code will automatically detect and use real assets when they're present in these paths:

```gdscript
# Example: Green Slime
assets/sprites/enemies/oakhaven/slime.png

# If found: Uses real sprite
# If not found: Uses ColorRect placeholder
```

No code changes needed! Just drop assets in the right folders.

## 🆘 Troubleshooting

### "Assets look blurry"
- Check Filter is set to "Nearest" (not Linear)
- Disable Mipmaps in import settings

### "Tileset not working"
- Ensure tiles are evenly spaced
- Check for transparency issues
- Verify tile size matches import settings

### "Asset not detected"
- Check file path matches expected location
- Ensure file extension is supported (.png recommended)
- Restart Godot to refresh asset cache
