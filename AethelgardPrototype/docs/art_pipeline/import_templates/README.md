# Phase 10M-N Import Templates

These templates are source-side guide sheets only. Do not copy a guide PNG into
`assets/production_art/` as a placeholder, because a production filename intentionally overrides
the generated fallback.

Run `create_phase10mn_import_templates.ps1` to regenerate:
- 512x512, 32 px grid sheets for Oakhaven, Ironhold, and Fractured Wastes production tilesets
- shared prop-atlas crop contract guide at 1536x1024
- shared decal-atlas crop contract guide at 1536x1024
- Tutorial Knight arena floor guide at 1280x720
