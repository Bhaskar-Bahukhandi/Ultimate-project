# Region Asset Requirements

## Integration Rules

- Production art should replace generated visuals through stable named slots; generated v3 and v2 remain fallbacks.
- Collision, interactable bodies, story triggers, combat timing, and save data stay independent from visual replacement.
- Top-down gameplay assets should keep characters readable at current scale: 32 px NPC frames, 32 px Kaelen top-down frames, 48 px enemy frames, and 32 px visual tile grid unless an explicit authored-scene migration is approved.
- Environment art should arrive as coherent tile families, grounded props, background plates, foreground silhouettes, and UI marker support rather than one-off overlays.
