# Oakhaven Tileset Import Slot

Use this slot for editable Oakhaven source art before export to
`assets/production_art/tilesets/oakhaven_tileset.png`.

The first production pass needs a coherent 32 px top-down family, not a platformer sheet:
- meadow floor variants with low-noise traversal tiles
- dirt path center, corners, shoulders, and soft blend edges
- cottage wall, base, roof-support, fence, and threshold tiles
- herb patch and exit-sign support tiles

Keep source licenses or generation notes beside the source files.
