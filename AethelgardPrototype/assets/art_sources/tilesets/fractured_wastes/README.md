# Fractured Wastes Tileset Import Slot

Use this slot for editable Fractured Wastes source art before export to
`assets/production_art/tilesets/fractured_wastes_tileset.png`.

The first production pass needs a coherent 32 px top-down family:
- cracked soil variants with irregular cadence
- scar edges and safe trail tiles
- shelter/core threshold tiles
- shard pocket and warning support tiles

Hazards must remain readable after the visual swap.
