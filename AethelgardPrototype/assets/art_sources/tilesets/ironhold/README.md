# Ironhold Tileset Import Slot

Use this slot for editable Ironhold source art before export to
`assets/production_art/tilesets/ironhold_tileset.png`.

The first production pass needs a coherent 32 px top-down family:
- calm industrial traversal floor and road tiles
- riveted edge and walkway transition tiles
- forge/training apron support tiles
- wall-base, plate, pipe, and ore/mine threshold support tiles

Avoid sheets that make the whole playable route equally noisy.
